Conectar la API de BBVA

Las cuentas, saldos y movimientos de BBVA se consultan por la API Accounts PSD2, a través del HUB de Redsys. Hace falta estar dado de alta como proveedor de información de cuentas (AISP) y un certificado electrónico eIDAS. Con el usuario y la clave de la app no se puede llamar a esa API.

  1. Alta del TPP en el HUB PSD2 de Redsys y certificado QWAC.
  2. Copia .env.example a .env en esta carpeta.
  3. Rellena BBVA_CLIENT_ID (formato PSDES-BDE-…), BBVA_CERT_PATH y BBVA_KEY_PATH.
  4. Reinicia el dashboard y pulsa Conectar. BBVA pedirá tu firma para un consentimiento de 90 días.

Para uso personal gratis: en bbva.es ve a Movimientos, descarga Excel o CSV e impórtalo con Importar extracto. Puedes subir varias cuentas; se fusionan. El ejemplo carga datos ficticios.
